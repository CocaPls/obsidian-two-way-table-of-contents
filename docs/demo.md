# Two-Way Table of Contents

```tw-toc
title: Contents
depth: 0
```

## Start here

Click a number in the table of contents to reach a section. Click its heading number to return.

### Keep your headings

Numbers appear in Reading view. Your Markdown headings and existing links stay unchanged.

#### Fold the details

Use the arrow beside a parent entry to collapse or expand its children.

### Choose the initial view

Everything starts expanded. In settings, 0 expands all and 3 folds H4 and deeper headings.

## Read and return

The return link opens only the path to the matching table-of-contents entry.

### Keep other branches folded

Folding does not change heading numbers or the source text.


## Command walkthrough

Right-click a table of contents to edit its overrides, inspect settings, or copy its outline. Use Find a heading to search this note, then Previous heading / Next heading to navigate. Copy current section content returns the original Markdown. Whole-TOC fold commands keep the global initial heading level unchanged.
