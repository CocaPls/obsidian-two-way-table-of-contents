# Two-Way Table of Contents

[English](README.md)

Obsidian 읽기 화면에 자동 목차와 선택적인 본문 번호를 표시한다. 목차 항목은 본문으로, 본문 번호는 문서의 첫 목차로 이동한다. 제목 원문과 저장된 제목 링크는 고치지 않는다.

## 사용

편집 화면에서 **Two-Way Table of Contents: 목차 삽입** 명령을 실행하면 삽입 창이 열린다. 전역 설정을 따르려면 바로 **삽입**, 해당 목차만 다르게 꾸미려면 **추가 설정**을 펼쳐 값을 지정한다. 취소하면 원문을 바꾸지 않는다. 다음 블록을 직접 입력할 수도 있다.

````markdown
```tw-toc
title: 목차
```
````

본문 번호의 설치 기본값은 꺼짐이다. 본문 자동 번호·제목 범위·기존 절 번호 대체·이동 시 펼침은 전역 설정창에서 정한다. 목차가 없더라도 본문 번호는 표시할 수 있다. 문서 속성은 읽거나 쓰지 않으며 문서별 번호 전환 명령은 없다.

삽입 창에서는 제목·위치·크기·배경·테두리·접기를 해당 목차만의 값으로 정할 수 있다. 따로 지정한 옵션만 블록에 저장하며 생략한 항목은 전역 설정을 계속 따른다. 기존 문서 속성을 복제하거나 변경하지 않는다. 속성 영역 안에서 삽입 명령을 실행하면 본문에 커서를 놓도록 안내한다. 창이 열린 사이 문서가 변경되면 삽입을 거절하고 다시 실행하도록 안내한다.

| 블록 옵션 | 값 |
|---|---|
| `title` | 문자열, 최대 200자, 빈 값 허용 |
| `position` | 0~100, 소수 허용. 0 왼쪽 / 50 가운데 / 100 오른쪽 |
| `scale` | 25~200, 소수 허용. 100 원래 크기 |
| `border`, `collapsible`, `branches`, `guides` | `true`, `false` |
| `depth` | 0~6 정수. 0 전부 펼침, 3은 H3까지 펼침 |
| `background` | `transparent` 또는 `#RRGGBB` / `#RRGGBBAA` |

블록 옵션은 한 줄에 `key: value` 하나인 제한된 형식이며 YAML 전체 문법을 지원하지 않는다. 유효하지 않은 항목은 안내하고 상위 기본값을 사용한다. 번호·범위는 블록별로 바꿀 수 없다.

## 위치와 크기

설정 화면의 **목차 위치 (%)**에 0~100을 입력한다. 기본값은 0이다. 각 목차는 `position: 50`처럼 블록에서 별도 값을 지정할 수 있다. 상자의 너비를 뺀 남는 공간을 비율로 나누므로 100에서도 상자 전체가 본문 안에 들어온다. 자동 너비와 접기 기능은 유지된다.

**목차 크기 (%)**에는 목차 전체의 상대 크기를 입력한다. `100`은 기존 크기, `80`은 글자와 상자 안쪽 여백·최소 크기를 함께 0.8배로 줄인 값이다. 각 목차는 `scale: 80`이나 `scale: 80%`로 따로 지정할 수 있다. 위치 방식과 내용에 맞춘 자동 너비는 바뀌지 않는다.

옆에 떠 있는 인포 콜아웃이 있으면 남은 본문 공간을 기준으로 정렬한다. 같은 높이에서 배치하려면 인포 콜아웃을 목차보다 먼저 적는다. 목차 뒤의 콜아웃을 위로 끌어올리는 기능은 아니다.

## 동작

- 기본 범위 H1~H6. 시작·끝 단계에 1~6의 정수를 입력한다. 시작≤끝이어야 하며 같은 단계만 포함할 수도 있다. 빈칸·소수·범위 밖·역전 입력은 저장하지 않고 이유를 표시한다.
- 빠진 단계는 1로 채운다. 범위를 H2~H4로 지정한 경우 H2→H4→H3는 `1.`→`1.1.1.`→`1.2.`로 표시한다.
- 목차는 숫자로 고정하며 번호만 본문 이동 링크다. 제목 글자는 클릭 이동을 하지 않는다. 본문 자동 번호는 목차가 있을 때 항상 첫 목차로 복귀하는 링크가 된다.
- 기본값은 수동 번호를 그대로 표시한다. 기존 절 번호 대체를 켜면 인식한 앞 번호만 화면에서 숨겨 중복을 막는다.
- 콜아웃·인용문·임베드·코드 예시의 제목은 제외한다.
- 목차 수와 무관하게 번호는 문서당 한 계산 결과를 사용한다. 복귀는 문서 순서상 첫 목차의 시작이며 해당 항목만 1.2초 강조한다.
- 본문 이동 자동 펼침은 기본 꺼짐이다. 켜면 필요한 조상과 대상 절만 펼친다. 본문 번호로 돌아올 때는 첫 목차 상자와 해당 항목의 상위 가지만 펼친다.
- 본문 번호는 읽기 화면 전용이다. 실시간 미리보기·모바일 지원은 포함하지 않는다. Markdown·텍스트 내보내기는 정적 목차를 생성하며 화면의 접힘·본문 자동 번호를 함께 내보내지는 않는다.

## 하위 항목 접기

하위 제목이 있는 항목의 화살표는 그 아래 목록을 접고 펼친다. 숫자는 본문으로 이동하며 제목 글자는 이동 버튼이 아니다. 목차 상자의 전체 접기 버튼은 별도로 동작한다.

설정의 **처음 펼쳐둘 제목 단계**에 0~6 정수를 입력한다. 기본값 0은 전부 펼침이며, 3은 H3까지 펼치고 H4부터 접는다. 1은 H1 아래의 항목을 접는다. 실제 Markdown H 번호가 기준이며 글자 크기나 목차 안에서 센 상대 깊이와는 다르다. 목차 상자에는 단계 선택창을 두지 않는다.

최상위 항목은 다시 펼칠 수 있도록 항상 보인다. H1 없이 H2부터 시작하는 목차에서 1을 입력하면 H2는 남기고 그 아래를 접는다. H2→H4→H3처럼 단계를 건너뛰어도 설정 3에서는 H4만 숨기고 H3는 보인다. 일부 자식만 보이는 가지는 화살표를 한 번 누르면 남은 자식을 펼치고 다음 클릭으로 전체 자식을 접는다. 번호 계산은 유지한다.

전역 설정의 **하위 항목 접기**는 기본 켜짐이다. 끄면 초기 제목 단계 입력을 비활성화하고 저장한 값은 보존한다. 블록의 `branches: false`는 화살표를 숨기고 모든 항목을 표시한다. `depth: 3`은 H3까지, `depth: 0`은 모두 펼쳐 시작한다. 생략한 값은 전역값을 따른다. `depth`는 상대적인 중첩 깊이가 아니라 실제 H 번호를 뜻한다.

열린 문서에서는 목차마다 접힘 상태를 보존한다. 제목 글자·단계·등장 순서로 기존 항목과 대응시키고, 개수가 같은 경우 같은 줄의 제목 변경도 보존한다. 같은 제목의 삽입·삭제·재배치가 겹치면 대응이 모호할 수 있다. 문서 전환·앱 재시작 후에는 처음 펼쳐둘 제목 단계 설정으로 시작하며, 접힘 상태를 원문이나 문서 속성에 저장하지 않는다.

본문 번호를 눌러 복귀하면 첫 목차와 해당 항목의 상위 가지만 펼친다. 다른 가지는 유지하며 해당 행만 약 1.2초 강조한다. 본문 접힘 설정과 목차 내부 접힘은 독립적이다.

## 첫 표시와 자동 갱신

목차 블록을 화면으로 만들 때 해당 문서의 내용을 바로 읽고 목차를 채운다. 첫 표시는 80ms 갱신 대기를 거치거나 다른 열린 문서의 읽기를 기다리지 않는다. 제목 정보가 아직 준비되지 않았으면 정보 도착 알림으로 다시 처리한다.

읽기 화면의 목차는 제목 수정·추가·삭제·단계 변경에 따라 자동으로 갱신된다. 변경 알림은 문서별로 80ms 동안 모아서 처리하며, 새 내용이 준비되는 동안 기존 목차를 유지한다. 문서 읽기와 화면 처리 시간은 별도로 들 수 있으므로 모든 환경에서 본문과 목차의 표시 시점이 같음을 보장하지 않는다. 편집 화면의 실시간 미리보기는 지원 범위에 포함하지 않는다.

## 제목 서식

목차 항목의 `**강조**`, `*기울임*`, `~~취소~~`, 인라인 코드는 기호 대신 해당 서식으로 표시한다. `C++`, 이스케이프한 별표, 코드 안의 기호는 제목 내용으로 유지한다. 제목 원문과 이동 대상은 바꾸지 않는다.

제목 속 마크다운 링크·위키링크는 표시 글자만 사용하고 원래 링크를 활성화하지 않는다. 이미지는 대체 글자로 표시하며 임베드·HTML·수식·사용자 플러그인의 확장 문법을 실행하지 않는다. 본문 제목에 사용자가 직접 작성한 원래 링크는 보존한다. 목차의 번호만 본문 이동 링크로 사용한다.

## 기존 절 번호 대체

설정의 **기존 절 번호를 자동 번호로 대체해 표시**를 켠다. 기본값은 false이며 모든 문서가 전역값을 따른다.

제목 원문 맨 앞의 `2. `, `2.1. `처럼 마지막 점 뒤에 공백 또는 탭이 있는 숫자만 인식한다. `2026년 계획`, `3·1 운동`, `2.1 안내`, `2.안내`, `**2.** 안내`는 그대로 둔다. `1984. 작품 해설`은 같은 모양이라 인식되므로 그 글자를 유지하려면 전역 설정에서 대체를 끈다.

대체를 켜면 목차의 제목에서 앞 번호를 숨긴다. 본문은 자동 번호도 켰을 때만 기존 번호 대신 계산한 번호를 표시한다. 자동 번호를 끄면 본문의 수동 번호가 그대로 보인다. 예를 들어 H2~H4 범위에서 원문 `## 7. 소개`가 첫 절이면 `1. 소개`로 표시하지만 원문과 기존 `#7. 소개` 링크는 유지한다. 번호 뒤의 굵은 글씨·링크·코드 요소는 교체하지 않는다. 대체를 끄거나 플러그인을 종료하면 원래 표시를 복원한다.

## 이전 설정의 전환

이전 개발본의 `tw-toc-*` 문서 속성은 설정에 반영하지 않으며, 플러그인이 이를 자동 정리하거나 새 속성을 만들지 않는다. 목차별 외형은 삽입 창에서 정하고 본문 번호·범위는 전역 설정을 사용한다.

이전 개발본의 목차 스타일·목차 클릭 범위·본문 복귀 토글은 적용하지 않는다. 기존 `style`의 number/bullet/none은 모두 숫자로, `links`의 marker/title/none은 모두 번호만 클릭하는 방식으로 표시한다. 전역 `returnLink` 값은 복귀 여부에 사용하지 않는다. 본문 번호가 켜지고 목차가 있으면 복귀가 활성화된다.

과거 유효값은 오류 없이 읽고 오타·잘못된 값은 안내한다. 문서 속성과 기존 코드 블록은 자동 수정하지 않는다. 저장된 제목 범위와 나머지 설정은 보존한다. 범위 값이 없으면 H1~H6을 사용한다. H2~H4만 쓰는 볼트라면 해당 범위를 지정한다. 본문 번호·기존 번호 대체·이동 자동 펼침의 기본값은 꺼짐이다.

설정 파일은 읽을 때 자동으로 다시 쓰지 않는다. 사용자가 플러그인 설정을 저장할 때 제거된 전역 항목을 제외한 구조로 저장한다. 과거 이동 끄기나 제목 전체 클릭을 사용한 문서도 번호 클릭으로 바뀐다.

## 개발

Node.js와 npm으로 설치·검사·빌드한다.

```sh
npm ci --ignore-scripts
npm run check
npm test
npm run build
```

빌드 산출물 `main.js`, `manifest.json`, `styles.css`만 볼트의 `.obsidian/plugins/two-way-table-of-contents/`에 설치한다. `node_modules`와 개발 소스는 복사하지 않는다.

`src/model.ts`는 입력 검사·수집·번호 계산을, `src/folding.ts`는 목차 접힘 상태를, `src/settings.ts`는 설정 화면을, `src/main.ts`는 Obsidian 생명주기와 표시를, `src/preview.ts`는 읽기 화면 이동과 크기 갱신을 담당한다. 제목의 인라인 서식 해석에는 번들에 포함한 markdown-it을 사용한다. 별도 Obsidian 플러그인 설치는 필요 없다. Obsidian 모듈은 앱이 제공하며 번들 라이브러리의 라이선스는 THIRD_PARTY_NOTICES.md와 실행 파일 머리부분에 포함한다.

## 호환성과 데이터

설치 대상은 데스크톱 Obsidian 1.13.7 이상이다. 읽기 화면의 소스 위치·접힘·가상 렌더링 제어는 공개 API만으로 해결되지 않아 `preview.ts`에 내부 렌더러 접근을 모았다. 앱 업데이트 후에는 중복 제목, 긴 문서, 접힌 절 이동을 다시 확인해야 한다.

네트워크 요청·텔레메트리·임의 HTML·평가식·원문 링크 일괄 수정 기능은 없다. 목차 항목은 텍스트와 허용한 인라인 서식 요소로, 목차 이름은 텍스트 노드로 표시하고 배경에는 제한된 색상 값만 허용한다. 파일 쓰기는 사용자가 확인한 목차 삽입·편집과 플러그인 설정 저장에 한정한다. 복사 명령을 직접 실행할 때 요청한 목차·제목 링크·절 내용만 시스템 클립보드에 쓴다. 기존 클립보드 내용은 읽지 않는다.

자동 시험은 `tests/`에서 수행한다. Obsidian 통합 검사는 실제 앱에서 별도로 수행한다. 개발 소스와 볼트에 설치한 실행 파일은 별도 경로로 관리한다.

## 언어와 배포

Obsidian 언어가 한국어이면 한국어 UI, 그 외에는 영어 UI를 사용한다. 사용자가 저장한 목차 제목은 번역하지 않는다. 제품 소스는 MIT 라이선스이며 번들 의존성 고지는 THIRD_PARTY_NOTICES.md에 있다. 릴리스 준비는 [배포 절차](RELEASING.md)를 따른다.

## 편집·검색·복사 명령

목차 상자 우클릭에서 **이 목차 편집**, Markdown·텍스트 복사, 설정·오류 확인과 전체 펼침·접힘·초기화를 실행한다. 항목 우클릭에서는 제목 링크·절 내용·하위 목차 복사와 해당 가지 접기를 실행한다. 명령 팔레트에는 같은 동작과 **목차에서 제목 찾기**, **이전 제목**, **다음 제목**, **첫 목차로 돌아가기**, **목차 옵션 설명 보기**가 있다. 기본 단축키를 강제로 추가하지 않는다.

편집은 기존 삽입 창을 재사용한다. 전역값을 따르는 항목과 이 목차의 예외를 구별하며 주석·모르는 옵션·변경하지 않은 값을 보존한다. ‘전역 설정으로 되돌리기’는 잘못된 개별 외형 값도 제거하되 주석과 모르는 옵션은 남긴다. 창이 열린 사이 원문이 바뀌면 저장을 거절한다. 여러 목차 중 대상을 확정할 수 없으면 선택 창을 연다. 닫히지 않은 코드 블록은 먼저 닫아야 한다.

복사는 접혀 있는 항목도 포함하고 문서의 번호를 유지한다. 절 내용은 제목과 하위 절을 포함한 원문이며, 절 목차는 선택한 제목 아래의 항목만 포함한다. 같은 제목이 여러 번 나오면 외부 링크가 목적지에서 구별되지 않을 수 있다. 검색·복사는 편집기에서도 동작하고 접기·목차 복귀는 읽기 화면에서 사용한다.

계층 가이드선과 본문 미리보기는 기본 꺼짐이다. 가이드선은 `guides: true`로 목차별 지정도 가능하다. 본문 미리보기는 숫자 링크와 Obsidian 페이지 미리보기 기능을 이용하며 보조키·소스 설정을 따른다. 제목 글자는 이동 버튼으로 바뀌지 않는다. 제목의 `==강조==`도 표시한다.

## AI와 자동화

공식 CLI에 `two-way-table-of-contents:inspect`, `validate`, `section`, `block`, `export`를 제공한다. 각 명령에는 동일한 플러그인 접두사를 붙인다. 저장된 파일을 기준으로 제목·번호·설정·오류를 조회하고 원문 해시와 행 번호로 절을 구별한다. 원문이 바뀌면 다시 조회하도록 오류를 반환한다. 파일을 자동으로 쓰거나 설정을 바꾸지 않는다.

[명령 상세](docs/COMMANDS.md)에 입력값·JSON 결과·실패 구분과 예시가 있다. 명령 실행에는 Obsidian과 해당 플러그인, CLI 활성화가 필요하다. 저장 전 편집 내용은 CLI 조회에 포함하지 않는다.


## 설정 검색과 개발 검사

Obsidian 설정 검색에서 ‘처음 펼쳐둘 제목 단계’ 등 전역 설정 이름으로 찾을 수 있습니다. 이동 중 해당 창이 숨겨지면 이동을 취소합니다. 창으로 돌아온 뒤 숫자를 다시 누르세요.

개발할 때 `npm run lint`로 공식 Obsidian 권장 코드 검사를 실행합니다. 배포 파일 준비와 수동 검수 항목은 [배포 절차](RELEASING.md)에 있습니다.
