# Changelog

## 0.1.0

- Add automatic Reading-view tables of contents with numbered heading navigation and optional display-only body numbers.
- Add independent branch folding, a whole-table fold button, and a numeric initial heading level; all entries are expanded by default.
- Add insertion and editing dialogs, heading search, previous/next navigation, context menus, and Markdown/text/section copying.
- Add read-only JSON CLI commands for inspecting, validating, exporting, and retrieving sections or table blocks.
- Add Korean and English interfaces, settings search, accessibility labels, and compatibility checks for desktop Obsidian 1.13.7 or newer.
